# Cohort Analysis - E-commerce Dataset

## Overview
This project performs cohort retention analysis on an e-commerce dataset 
using SQL Server.

## Tools Used
- SQL Server (SSMS)

## What this project does
- Identifies customer cohorts based on their first purchase month
- Tracks how many customers return in subsequent months
- Calculates retention rate for each cohort
- Visualizes results as a cohort matrix

## Files
- `Cohort_Analysis.sql` — Contains all SQL queries with CTEs for cohort analysis
